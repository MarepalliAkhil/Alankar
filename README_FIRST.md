# Starter kit

**Using the Claude app project "Alankar"? Read `docs/CLAUDE_PROJECT_SETUP.md` first** (folder, project instructions, first message).

This folder is ready to open in Claude Code.

1. `git init` in this folder (install Git for Windows first if you haven't).
2. Open the folder in Claude Code (desktop app Code tab, or run `claude` in a terminal here).
3. Paste the first message from `docs/START_HERE.md` (Step 3), check the summary, then run Task 0 (Step 4).
4. After every task: tests pass, update `docs/PROGRESS.md`, `git commit`.

Files:
- `CLAUDE.md`: the rules Claude reads every session (edit section 9 "Defaults" if you disagree).
- `docs/MASTER_NOTES.md`: the full plan (source of truth).
- `docs/CHATBOT_ALGORITHM.md` + `reference/chatbot_reference/`: the chatbot spec and tested reference code.
- `docs/archive/`: older prompt files, for reference only; where they conflict with MASTER_NOTES, MASTER_NOTES wins.
